Design notes

  • Flow: Mode → Limits → Passes → Permission → Review & lock. Block mode skips Limits and Passes. The guard does nothing until the last step is approved.
  • Throttle popup: every number (scrolling, session length up to 24 h, passes, pass length, lock period) is set with the same pop-up throttle lever. Drag the handle, it clicks into detents. Push up for more.
  • Locked: the lever can't go above the current setting. The hatched barrier marks the blocked zone and the handle bumps against it. In the settings you can still pull it down (stricter).
  • Lock: approval is a deliberate press and hold, plus a lock period you pick. The main screen shows only the timer; settings sit behind the gear in the top right corner.
  • Editing: while locked you can only go stricter (applies instantly). After the lock ends, going up is a request with a 24 h wait, then a review and hold-to-apply. Use the buttons below to see each state.
  • Known gap: a lock stored in app data can be cleared by uninstalling or "Clear data". Hardening ideas: warn on the first launch after a reinstall, and gate on the accessibility service being on.
  • Mockup only: nothing here is wired to the app. "Restart mockup" on the main screen starts over.
